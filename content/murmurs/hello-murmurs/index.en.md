## What this section is for

Technical articles stay in the home feed, while this section is only for life stuff: daily notes, moods, trips, random thoughts — anything goes.

## How to publish here

Create a new folder under `content/murmurs/` (e.g. `content/murmurs/my-day/`) with an `index.md` inside, copy the front matter from this post, then `git push`. GitHub Actions will build and deploy automatically.

Feel free to delete or rewrite this sample post anytime.
